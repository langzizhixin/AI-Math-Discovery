####  Let A₁A₂…Aₙ be n points on a circle, and let P be another point on the same circle. In each round, orthogonally project P onto the supporting lines through consecutive vertices; then repeat the operation using the lines through consecutive points of the resulting pedal polygon. The paper claims that after n−2 iterations the n resulting points are collinear, and that after n−1 iterations all n points coincide. For n=3, the statement reduces to the classical Simson–Wallace theorem.
####  设 A₁A₂…Aₙ 为同一圆上的 n 个点，P 为该圆上的另一点；从 P 向相邻顶点所确定的直线依次作垂线得到第一轮垂足，再以第一轮垂足相邻点的连线为新边重复同样操作。本文证明：经过 n−2 轮垂足变换后，所得 n 个点必共线；进一步，经过 n−1 轮变换后，所得 n 个点全部重合。该结论在 n=3 时退化为经典西姆松—华莱士定理。
